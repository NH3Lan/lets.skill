# lets.skill

> 一门研究初代豆瓣女神的互联网学科，以 Claude Code Skill 的形式复现。

## 这是什么

`lets.skill` 是一个 Claude Code Skill，基于公开资料对「晚学」现象进行系统整理，提炼其核心表达框架，供研究者使用。

它不只是语录合集——它试图还原一种特定的表达逻辑：**在日常随意中嵌入信息不对称，用拒绝分享代替炫耀，用不回应代替辩解。**

## 核心框架

| 框架 | 核心逻辑 |
|------|---------|
| **没有义务分享** | 被问品牌/来源/价格 → 不解释，直接堵死 |
| **脚尖管理学** | 用姿态弥补客观现实的不足 |
| **花小钱装大杯** | 所有展示资产，实际价值远低于展示价值 |
| **陷阱题不接球** | 凡能勾连历史黑料的问题，沉默优先 |
| **沉默应对定律** | 凡争议不回应，用新内容转移注意力 |

## 语料来源

- 晚学经典课件索引（语录系列 / 财富管理 / 社交攀附 / 品牌翻车等）
- 晚学家生态与二创（豆瓣 / 小红书 / B站 / 抖音 / YouTube）
- 瀚语言文学分支学科
- 各平台公开讨论与学术研究整理

## 使用方式

在 Claude Code 中输入 `/wanwan`，或触发词：

```
/lets
让我用晚学视角分析一下
这件事套用一下脚尖管理学
```

## 诚实的边界

这个 Skill 无法做到：
- 还原她未公开的私下状态
- 预测她对具体事件的真实反应
- 覆盖 2025 年后的最新动态（持续更新中）

## 关于「晚学」

> 晚学是中国互联网「凡尔赛文化」最早的案例之一。与花学、九学、明学并列豆瓣江湖四大学。小红书 #晚学# 话题浏览量超 102 亿。晚学风口里唯一没挣到钱的，是本人。
