## 这是什么

`lets.skill` 是一个 Claude Code Skill，基于公开资料对「晚学」现象进行系统整理，提炼其核心表达框架，供研究者使用。

它不只是语录合集——它试图还原一种特定的表达逻辑：**在日常随意中嵌入信息不对称，用拒绝分享代替炫耀，用不回应代替辩解。**

---

## 5个核心框架

| 框架 | 核心逻辑 |
|------|---------|
| **没有义务分享** | 被问品牌/来源/价格 → 不解释，直接堵死 |
| **脚尖管理学** | 用姿态弥补客观现实的不足 |
| **花小钱装大杯** | 所有展示资产，实际价值远低于展示价值 |
| **陷阱题不接球** | 凡能勾连历史黑料的问题，沉默优先 |
| **沉默应对定律** | 凡争议不回应，用新内容转移注意力 |

## Skill 能做什么

- **角色扮演模式**：以第一人称回应，语气、边界、拒绝方式来自真实语料
- **研究者模式**：调用完整晚学课件库，分析具体事件的晚学坐标
- **陷阱题识别**：自动判断哪些问题会踩历史黑料，并给出正确的不接球处理
- **瀚语言文学分支**：林瀚相关经典语料单独可调用

## 语料来源

### 一手语料（本人直接产出）
- 豆瓣原帖、微博原文、小红书发帖
- 采访记录（松果LIFE+、Hi艺术等）
- 直播切片语录

### 晚学课件体系
- 经典课件：语录系列 / 财富管理 / 社交攀附 / 品牌翻车 / 家世管理
- 晚学家生态：豆瓣 / 小红书 / B站 / 抖音 / YouTube 各平台玩法
- 瀚语言文学分支学科
- 学术研究：武汉大学媒体学者刘嘉音专项论文

## 诚实的边界

- 基于公开信息整理，非本人授权或认可
- 语料截止：2025年（持续更新中）
- 私下状态、未公开言论不在此 Skill 范围内
- 面对从未公开讨论的议题，Skill 会基于框架推断，推断 ≠ 真实反应
